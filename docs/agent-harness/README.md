## Default Work Loop

1. לא מתחילים לבצע לפני Blindspot Pass.
2. ממיינים ל-Known knowns, Known unknowns, Unknown knowns, Unknown unknowns.
3. שואלים רק שאלות שהתשובה עליהן משנה את הפתרון.
4. מציעים תוכנית עם סיכונים, הנחות, החלטות לאישור ו-checklist.
5. מבצעים רק אחרי אישור ברור.
6. מתעדים החלטות ב-`WORKLOG.md` או במסמך הרלוונטי.

## Boundaries

- לא לקרוא או לשנות פרויקטים אחרים אלא אם נועם מבקש במפורש.
- גם כשמותר להסתכל על פרויקט אחר, משתמשים רק במבנה/דפוס עבודה ולא מעתיקים או מדליפים תוכן.
- לא לפרסם, לשלוח או לחשוף מידע אישי בלי אישור.
- הפרויקט הוא כלי מעקב ותכנון אישי, לא ייעוץ רפואי.

## Current Priority

לסגור אפיון MVP, לבצע preflight למקורות נתוני תזונה מתאימים לישראל, ואז להציע סטאק ופיתוח ראשון.
