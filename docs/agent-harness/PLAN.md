# Fit Plan Plan

## Phase 1 - Harness

- ליצור מסמכי harness.
- לתעד אפיון ראשוני.
- לרכז החלטות פתוחות.

## Phase 2 - Nutrition Data Preflight

- לבדוק מקורות נתוני תזונה למוצרים בישראל.
- לבדוק אפשרות לחיפוש/AI עבור טקסט חופשי בעברית.
- להציע מקור נתונים ראשון ל-MVP.

## Phase 3 - Technical Proposal

- להציע סטאק PWA + שרת.
- להגדיר מודל נתונים סופי ל-MVP.
- להגדיר מסכי MVP.
- להגדיר דרך deployment וגיבוי.

## Phase 4 - First Implementation Slice

- שלד PWA mobile-first RTL.
- API בסיסי לשמירת נתונים.
- Dashboard פשוט.
- הזנת משקל.
- רישום ארוחה ידני/טיוטה.

## Phase 5 - Food Parsing

- פירוק טקסט חופשי.
- התאמת מוצרים.
- מסך בחירת מוצר.
- שמירת מאקרו.
