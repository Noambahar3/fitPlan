# Fit Plan Checks

## MVP Behavior Checklist

- Dashboard מציג קלוריות שנאכלו היום.
- Dashboard מציג קלוריות שנותרו.
- Dashboard מציג גרף משקל.
- Dashboard מציג מאקרו יומי.
- אפשר להזין ארוחה בטקסט חופשי בעברית.
- המערכת מפרקת ארוחה לפריטים.
- המערכת מציגה קלוריות, חלבון, פחמימה ושומן.
- מוצרים לא ודאיים מוצגים לבחירה.
- מוצר לא מדויק מוצג כהערכה ולא כעובדה.
- אפשר לתקן לפני שמירה.
- אפשר להזין משקל.
- משקל נשמר ומופיע בגרף.

## Dietary Rules Checklist

- אין אפרסק בהצעות.
- אין ערבוב בשר וחלב באותה הצעת תפריט.
- פירות לא מוצעים כעמוד תווך של התפריט.
- מאכלים מועדפים נשמרים ומתועדפים.

## Mobile Checklist

- עובד היטב במסך טלפון.
- RTL תקין.
- כפתור הוספת ארוחה נגיש מהר.
- אין עומס טקסט במסך הראשי.
- אפשר להשתמש ביד אחת.

## Server Checklist

- הנתונים נשמרים אחרי רענון.
- אין פעולות מחיקה פתוחות ללא הגנה מינימלית.
- יש גיבוי או לפחות נתיב ייצוא עתידי.
