# Fit Plan Runbook

## Daily Work Start

1. לעבוד מתוך `/home/noam/.openclaw/workspace/fit-plan`.
2. לקרוא את `README.md`, `SPEC.md`, `PLAN.md`, ו-`WORKLOG.md` אם צריך הקשר.
3. לבצע Blindspot Pass לפני ביצוע שינוי.
4. לוודא שאין תלות בפרויקט אחר.

- לא להציג את המערכת כייעוץ רפואי.
- להחריג אפרסק מכל הצעה.
- לכבד כשרות בשר/חלב.
- להעדיף ניסוח של מעקב, הערכה ותכנון.

## Handoff Procedure
